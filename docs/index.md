# Verilog HDL 语法指南

本指南面向**数字 IC 设计工程师**，系统讲解 IEEE 1364-2005 标准 Verilog HDL 语法，覆盖一名合格工程师应掌握的完整范围：语言基础、典型电路的推荐写法、可综合性规则、命名规范与验证基础。

## 本指南的可靠性保证

本指南中所有可运行的代码示例都以 `examples/` 目录下的 `.v` 文件为**唯一真源**：

- 每个示例都经 **Icarus Verilog 12（`-g2005` 标准开关）编译**通过；
- 每个示例都配有**自检测试台**，经 `vvp` 仿真运行并通过 `PASS` 断言（见第 15 章约定）；
- 文档通过 snippet 机制直接嵌入示例文件本身，**文档与代码在物理上不可能漂移**；
- 任一示例编译、仿真或一致性检查失败，全站构建即失败（`tools/check.py`）。

## 标注图例

| 标注 | 含义 |
|---|---|
| ✅ / `!!! success` | **可综合**：可用于 RTL 设计，综合工具普遍支持 |
| ❌ / `!!! danger` | **不可综合，仅仿真**：只能用于测试台或仿真模型 |
| ⚠️ / `!!! warning` | **慎用**：行为依赖工具或易引入隐患，需充分理解后使用 |
| `!!! tip` | **推荐写法**：工程实践中的首选风格 |

## 使用方法（全程离线）

```bash
python tools/check.py              # 一键总检查：示例校验 + 严格构建 + 外链审计
python tools/serve.py --open       # 离线浏览构建产物（禁止双击 index.html）
```
