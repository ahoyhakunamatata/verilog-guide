# 03 表达式与操作符

本章介绍操作符体系、表达式位宽规则与求值规则——这是 Verilog 中**最易出错**的部分，多数"仿真与综合不一致"的 bug 都源于对位宽/优先级/符号性的误解。

## 3.1 操作符全表

| 类别 | 符号 | 说明 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `%` `**` | `**` 为 2001 新增幂运算；`/` `%` 除数为 0 时结果为 x |
| 关系 | `<` `<=` `>` `>=` | 结果为 1 位 |
| 相等 | `==` `!=` `===` `!==` | `===`/`!==` 见 3.2 |
| 逻辑 | `&&` &#124;&#124; `!` | 非零即真，结果 1 位 |
| 位操作 | `&` &#124; `^` `~` `~^`/`^~` | 逐位运算，结果保持位宽 |
| 缩减 | `&` &#124; `^` `~&` `~`&#124; `~^` | 一元形式：折叠为 1 位 |
| 移位 | `<<` `>>` `<<<` `>>>` | `<<<`/`>>>` 算术移位为 2001 新增，见 3.4 |
| 拼接 | `{}` `{{}}` | 拼接 / 重复拼接 |
| 条件 | `?:` | 三目，右结合 |

## 3.2 相等比较：`==` 与 `===`

| 操作符 | x/z 参与比较时的结果 | 适用场景 |
|---|---|---|
| `==` `!=` | 任一操作数含 x/z 则结果为 **x** | ✅ 可综合（硬件中无 x/z 概念） |
| `===` `!==` | 逐位严格比较，含 x/z 也能得出 0/1 结果 | ⚠️ 仅仿真（TB 中比较含 x/z 的信号） |

!!! warning "仿真与综合差异"
    RTL 代码中不要用 `===`/`!==`（不可综合）；但**测试台比较可能含 x/z 的信号时必须用 `===`**——本指南所有 TB 的自检比较都用 `===`/`!==` 正是这个原因。

## 3.3 优先级（IEEE 1364-2005 Table 5-2）

**从高到低**（同一行内按书写顺序从左到右结合）：

| 优先级 | 操作符 |
|---|---|
| 最高 | `+ - ! ~ & ~&` &#124; `~`&#124; `^ ~^ ^~`（一元） |
| | `**` |
| | `* / %` |
| | `+ -`（二元） |
| | `<< >> <<< >>>` |
| | `< <= > >=` |
| | `== != === !==` |
| | `&`（二元） |
| | `^ ~^ ^~`（二元） |
| | &#124;（二元） |
| | `&&` |
| | &#124;&#124; |
| 最低 | `?:` |

!!! danger "与 C 语言相反的两处优先级"
    1. **Verilog 中二元 `+ -` 优先级高于移位 `<< >>`**（C 语言恰好相反）：`a + b << 1` 在 Verilog 中是 `(a+b)<<1`！
    2. **位操作 `&` 优先级高于关系与相等**（C 语言相反）：`a & b == 0` 在 Verilog 中是 `a & (b==0)`！

    处理办法只有一个：**拿不准就加括号**。本指南示例 03-7 演示了第 1 条陷阱。

## 3.4 移位规则

- 移位量**自我决定**（self-determined），不受上下文影响
- `<<` 左移：右侧补 0；`>>` 逻辑右移：左侧补 0
- `>>>` 算术右移：**对 signed 操作数左侧补符号位**，对 unsigned 等价于 `>>`；`<<<` 与 `<<` 相同（2001 新增）
- 移位结果位宽 = 左操作数位宽（受赋值上下文影响）

## 3.5 位宽与求值规则（重点）

**两类求值规则：**

- **上下文决定（context-determined）**：算术、位操作、关系、相等、逻辑等二元操作，表达式位宽 = `max(左操作数, 右操作数, 赋值目标)`，操作数先扩到该位宽再运算
- **自我决定（self-determined）**：一元操作符（`~`、缩减等）、移位量、拼接/重复拼接的各段、条件操作符的条件部分——不受上下文影响

**常见陷阱：**

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 进位丢失 | `wire [7:0] s; assign s = a + b;`（a、b 为 8 位）——加法在 8 位上下文求值，进位被丢 | 把 LHS 声明为 9 位：`wire [8:0] s;` |
| unsized 常量 32 位 | `assign y = a + 'd1;` 中 `'d1` 按至少 32 位参与运算，可能把整个表达式位宽撑大 | 常量一律写全位宽：`8'd1` |
| 域选越界 | 域选超出声明范围的部分返回 x | 检查索引范围 |
| 有符号混合 | signed/unsigned 混合时按标准符号规则扩展，规则易忘 | 见 3.6，必要时显式 `$signed()` |

## 3.6 有符号与无符号

- Verilog-2001 起可用 `signed` 声明：`wire signed [7:0] s;`；`integer` 默认有符号，其余默认无符号
- 混合运算规则：**只要任一操作数无符号，整个表达式按无符号处理**（`$signed()` 为 2001 新增系统函数，可强制按有符号处理）
- 关系比较（`<` 等）：任一操作数无符号则按无符号比较——`signed_a < unsigned_b` 可能得到反直觉结果

!!! tip "推荐写法"
    参与算术/比较的向量要么全部 signed 声明，要么显式用 `$signed()`/`$unsigned()` 转换，禁止隐式混合。
